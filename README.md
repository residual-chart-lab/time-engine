## v1で動くもの

一輪で選択・実行・認証・差の保持・停止を行い、その実際の出口を次の輪へ継承する。構成は**同階層の三輪＋上位の一輪**。一輪の完了と停止は正常な運動単位である。

指定した64経路の比較では、局所では成立する一輪目の4候補が、共通上位未来要求の下で1候補へ絞られる。除外された各候補は、指定した後続16通りでも成立しない。共通未来文脈を替える対照では、残る候補も変わる。

選択の確定後は再探索せずに実行し、三出力で上位セルを閉じる。実際の有理数終点を要求値へ丸めず、入れ子の履歴と二つの完全な完了記録を保存する。

**未来要求は通過可能性を定め、現在が選択する。** Cに選択や駆動の役割を追加しない。

上位未来文脈は明示した可解fixtureであり、候補照合には有限列挙を使う。独立した未来供給原理・任意経路への一般化・輪数一般の単調な拘束強化は未導出。未来因果は研究の中心仮説として保持し、模型で確認した作用と一般的な真理の証明を区別する。
