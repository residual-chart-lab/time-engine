# 局所的な非一意性は、マクロの非一意性を意味しない

2026-10-16。アキの指示を受け、RR51以後の研究の足場として固定する。

**局所的な非一意性は、マクロの非一意性を意味しない。**

一輪の未来要求が結果を拘束しても、現在の花びらの自由を全て奪う必要はない。一輪に複数の成立履歴が残ることは、今回の一輪模型では許容する。一輪だけで許容履歴を唯一に絞ることを、完成条件へ追加しない。

「実際に起きた一つの履歴を確定して記録すること」と、「許容される履歴が一つしかないこと」は異なる。前者の実行・記録は必要だが、後者を一輪の要求にはしない。RR51で残った候補の複数性を、そのままマクロの自由や非一意性へ外挿しない。

アキの構想では、次のフラワー、さらにその次のより大きなフラワーへ接続・包含されるにつれ、最初のフラワーに課される拘束が強まり、マクロでは一意に搬送される。三つのフラワーの接続が最初のフラワーの拘束をさらに強めるという見通しも、この次段階の構想として保存する。今回の一輪計算の検証結果とは分ける。

当面は一輪内部の成立、自由を残した履歴の実行・認証・保持を対象にする。接続の累積と階層化による拘束の強まりは、次フラワー以降の計算で検討する。
