# RR54 原本対応と、未来要求の位置

親コミット `5d8f222a595996919842caf47807225f4669533a`。RR53 v001の数理実装とv002の保持・変換の補足を維持する。

| 原本・足場 | 今回の対応 |
|---|---|
| v18 CG1・§7 | 共通の未来要求を先に束縛し、三輪全体で適合する候補から現在の一輪目を選ぶ |
| v18 §14.2・§14.3 | 各境界を認証して接続し、三つのlevel 3出力を別の上位Decoderで最初の境界へ閉じる |
| v18 CG5・§15 | 上位の一作用の語に、三つの入れ子の認証済み履歴を保持する |
| RR46〜48 | 各輪の現在補正と自己生成内部未来文脈での適合を保つ |
| RR51〜52 | 可能な候補とactualな一履歴を分け、確定後に経路を選び直さない |
| RR53 | 同じ接続則で二輪目から三輪目へ拡張。actualな状態・在庫・履歴を継承する |
| RR53 v002の蛹の補足 | 保持した構造・liveな参照文脈の変換・新しいsourceと運動の生成を分ける |

新しく宣言した条件は、三つの出力を受ける共通の上位未来フレームと、その可解な検査fixtureの構成である。ここを、原本から独立に導出済みの未来生成則とはしない。

三輪の局所閉鎖だけでは一輪目の四候補は全て残る。共通の上位要求を課した場合に、その有限比較クラスで一候補へ絞られる。上位要求を外し、各候補が自分用のフレームを作り直せる対照では四候補が戻る。

v18原本は同梱 `sources/v18-original.md`。SHA-256 `788cd5e7ce984bd450ec443a2e86ebdc2926bf139e38bc7f4929cc4bc5f05e1f`。全階層・全未来に対する一意性定理への外挿は行わない。
