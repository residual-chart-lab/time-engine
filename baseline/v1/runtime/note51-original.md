# RR51 — 局所選択の反例と、成立する全履歴の競合

2026-10-15。RR50から、作用の競合・確定が一輪の原理から生じるかを続けて調べる。

**RR50の局所選択は、そのまま一般の内部法則にはできない。同じ公開在庫と到来文脈でも、二作用で閉じられる開いた状態から、局所最小選択が閉じない運動を生成する反例がある。** 終端まで適合する候補を保持すれば、閉じる道は回収できる。ただし候補の一意な確定はまだ導出できていない。

RR50の元の入口での成功は撤回しない。今回の反例は、基準二枝の同じ在庫・文脈に対し、別に与えた診断用の開状態である。34摂動模型の全域で失敗するという主張でもない。

## 1. 局所の「よさ」と、一輪の成立を切り分ける

RR50の選択は、今の累積値zに次の一作用aを使った結果の不一致

$$m(a\mid z)=|k_a(Y)z-F|$$

を最小にする。一方、v18 §7の選択対象は、結果に適合する**全履歴**である。両者が同じ働きをするとは限らない。

基準二枝で、headのkernelをhとする。公開済み在庫と内部文脈はそのままに、RR49のhead実行済みsectionへ

$$z_0=-\frac1{h^2}$$

という別の開状態を与える。元の入口や継承値を後から変更したものではなく、既存の一輪の実prefixから到達した状態とも数えない。head実行済みsectionなので、診断の次作用をheadへ固定する条件は無い。

この状態は、在庫のheadを二回使えば**exactにF=−1へ閉じる**。途中の一回では閉じず、元のDecoderによる第一境界の証人を作れる。新しい作用を足す必要はない。

ところが、局所最小の選択は最初にheadを選ばない。

## 2. exactな成立根でも、応答値が閉じない二値を繰り返す

小さい負の軸応答をp、もう一つのhead軸応答をqと書く。基準第一枝ではpが第一軸、第二枝ではpが第二軸である。

$$h=pq,\qquad s=\frac1h$$

がexactな成立根で成り立つ。sは公開されたsourceの応答である。

診断用状態z₀からの局所選択は

$$p,\ p,\ s,\ h,\ s,\ h,\ldots$$

となる。二回目の軸作用後をu、その後にsourceを使った値をvとすると

$$u=-\frac1{q^2},\qquad v=-\frac1{hq^2},\qquad su=v,\quad hv=u.$$

uとvはFからε以上離れている。各段階で、その作用の不一致の上限が、全ての競合作用の不一致の下限より小さいことを、有理区間演算で証明した。根の区間は符号反転を保つ二分法で得ており、浮動小数の一点評価からの推測ではない。

これは**liveな応答値の二値反復**である。full stateには実行語が追加され続けるため、完全な内部状態が周期的に戻るとは言わない。

| 基準枝 | 診断開始値の概数 | 反復する応答値の概数 |
|---|---:|---|
| 第一枝 | −28476.49 | −0.005487 と −0.925955 |
| 第二枝 | −492798.07 | −0.001372 と −0.962965 |

表の概数は有理近似模型からの表示。exact根での反復は上の恒等式と区間不等式による。実装した有理近似sourceではhsは1と微小に異なるため、値は僅かに漂う。実装について確認したのは8作用以内で閉じないことであり、近似実装の無限時間非閉鎖を主張しない。

同じ診断状態のhead→headは誤差0で閉じる。このため、局所選択を全履歴の結果不一致最小化と同一視することはできない。ここで問題なのは運動の振れや計算コストではなく、**成立できる一輪があるのに、その選択規則が成立まで運ばないこと**である。

## 3. 全語の成立条件を保つと、閉じる道を回収できる

比較実装では、同じ在庫・文脈・要求から有限語を生成し、次を全て保つ。

- 非空語である。
- 途中の非終端はε外、終点はε/2内である。
- 途中で一度閉じた語を、同じ一輪の続きとして伸ばさない。
- 同階層の公開済み在庫だけを使い、各候補に元のDecoderの成立証人を付ける。

局所不一致の順位やDで枝を捨てない。探索上限1では診断状態の成立語は無いが、上限3では二枝それぞれ7本の認証可能な語が残り、その中にhead→headが含まれる。

**局所選択の最初の軸作用も、別の継続を選べば成立できる。** 上限3では最初の作用が第一軸、第二軸、headである候補が残る。未来要求がその最初の作用を全面的に禁止する、あるいは最短語だけを要求する、という結果ではない。問題は、毎回局所選択をし直す規則が、成立する継続を選び続ける保証を持たないことだ。

元のRR50入口から上限4で調べると、head→sourceとhead→head→source→sourceの二本が残る。両方を認証可能な異なる履歴として保持し、最初に短い成功を発見した時点で後者を捨てない。

この上限は計算の範囲であり、内部で発生した締切ではない。「上限内で未発見」を全長の不可能性としない。「上限内で候補が一つ」を、全継続に対する一意性ともしない。

候補の証人は**可能な継続の検証結果**であり、実際に選択・実行・公開された出来事ではない。在庫に候補を全部追加せず、過去の複数の未選択sourceを持ち越して選び直すこともしない。現在のsourceと到来文脈は確定したままである。

## 4. 「外へ残差を散らさない」は、何を与えれば計算できるか

v18 §29のhard条件は、隣接する閉鎖jに課す残差増分Δe*ⱼ,ext≤0である。しかし現在の一輪模型には、次が具体化されていない。

- 外部のどのセルを隣接相手とするか。
- 選択した履歴がその相手へどう作用するか。
- どの状態差を外部残差として測り、何を前後の基準とするか。

これらが無い場合は`UNDEFINED_EXTERNAL_COUPLING`を返す。隣接相手のデータが空だからhard条件を通過した、と扱わない。ソフトな経路損失も、その式があるだけで必要な評価量が定まるわけではない。

内部で既に使う三つの文脈で、短い語と遠回りのfull kernelを比較した。現在の補正文脈では両者はexactに同じ恒等作用を持つ。一方、headの認証元の文脈で読むと応答が異なる。**差は残っているが、この読出しの違いだけを隣接セルへの損害と数えることはできない。**

不足を見える形にするため、二種類の外部応答模型を明示して比較した。いずれも今回追加した診断用の結合・評価であり、実際のTime Engineの隣接セル模型を導出したものではない。

| 明示した外部結合と評価 | 短い語 | 遠回り |
|---|---|---|
| 外部成分への作用を恒等とする積模型 | 増分0 | 増分0 |
| 現在の補正文脈を共有し、外部スカラー残差を測る積模型 | 増分0 | 増分0 |
| head認証元の文脈を共有し、同じ外部スカラー残差を測る積模型 | 増分正 | 増分正 |

最初の二つでは両方が残り、最後では両方が落ちる。どの外部結合・残差評価が原本のe*ⱼ,extに当たるかが未確定のまま、欲しい一方を選ぶ装置として使ってはいけない。全ての結合模型で選別不能、という不可能定理ではない。

## 5. 原本との対応と、今回わかった未完成部分

v18の二境界適合は、現在から実行可能で、未来要求にも適合する全履歴の集合を制約する。これは今回、在庫から生成した全語の成立証人として計算できる。

しかし、成立する集合を得ることと、一つを確定して最後まで実行することは別である。原本§7の第二段階の経路損失、§29の外部残差評価は、今回の具体模型ではまだ選択器として完成していない。RR50の局所argminで置き換える一般的な根拠は、今回の反例により失われた。

一輪が有限の第一境界へ閉じるという要求は、閉じない局所規則の無限継続を、完成した一輪として数えることを許さない。一方、それだけで有限な複数の成立履歴から唯一の道が決まるわけではない。

**唯一の道が数学的に導かれることを、最小模型の完成条件に追加する必要はない。** 複数の成立履歴が許されてもよい。いま不足しているのは、そこから一つを確定し、選んだ成立を最後まで実行する具体機構である。今回の候補保持は、その前段までを計算したものとして扱う。

次に具体化すべき対象は、**成立する全履歴を保持した上で、どの差を保存し、何を基準に一つへ確定するか**である。最短距離、安定稼働、低コストを新しい原理として先に置かない。RR49の適合集合の厳密包含と、RR50の指定近傍での局所実現は保持するが、全運動のD減少へは広げない。

sourceの生成則・成立枝・固定F・文脈読出しの由来も未導出のまま残る。次フラワー接続は今回の主問題にしない。
