# RR53 原本対応と接続の型

親：`0b3b27b35ce53a70bf20c29129464bbe8b679e0e`（RR52 v002）。元の一輪の完成・保存後の作用を足場にする。ユーザー指示は `user-directive-rr53-original.md`。

| 原本・足場 | 今回の具体化と範囲 |
|---|---|
| v18 CG1、§14.2 | 一輪目のactual終点を二輪目の継承状態へする。境界に揃った接続と、freshな入口へのリセットを分ける |
| v18 CG2、§15 | level 3のexact出力を保持。level 2在庫へ混ぜず、宣言した文脈接続口で保持差を読む |
| RR43 | 二本の実行状態・在庫・出力・round・eventを継続させる |
| RR44 | 順序付きprimitive葉の読出しを、終端作用の全葉へ拡張。今回の接続候補であり、原本の生成則の唯一の導出とはしない |
| RR46〜48 | 二輪目でも現在補正に残る一自由度を、自己生成の内部未来文脈での成立で拘束する |
| RR51 | 全語の成立候補と実際の選択を分け、局所argminの反例を維持する |
| RR52 v001/v002 | 元の確定後の実行器・close・exact記録の型を再利用。二輪目は新しい接続専用入口で認証する |

新しい宣言条件は、終端葉の順序付き読出し、headを基準とする文脈への結合、強さη、二輪目のsource根の枝と有限探索域。未来の完成済み経路を外部入力として渡すAPIにはしない。

同梱 `sources/v18-original.md` は固定原本、SHA-256 `788cd5e7ce984bd450ec443a2e86ebdc2926bf139e38bc7f4929cc4bc5f05e1f`。旧成果の詳細な対応は `RR52-v002-source-map.md` / `RR52-source-map.md`。v18の全階層を今回実装したという対応ではない。

一輪目の四完了記録はRR52公開版のバイト列と一致する。二輪目はそこからsourceを新たに実行・認証して作った結果であり、事前に保存された二輪目の答えの再生ではない。
