# RR52 v002 — 一輪の再点検と、保存された過去差の操作的な再参照

2026-10-16。今回の指示書は `user-instruction-recheck-original.md` に原文のバイト列のまま保存した。

**一輪の選択・実行・認証・保持・停止というRR52 v001の結論は維持できた。今回不足していたのは、保存・復元した完了記録を後の作用に使う検査である。これを追加し、履歴差が新しい参照状態を実際に変えることを確認した。** 元の一輪計算を修正する数値的・認証上の欠陥は、今回の再点検では見つからなかった。

ただし「同じ結果」は、元から固定した要求 F=−1 と ε=10⁻¹²を共に満たす、という意味である。短い道と遠回りの実際の有理数終点は僅かに違う。この差を隠さず、終点の倍率差だけでは説明できない読み取りも検査した。

## 2. 成立前の未来要求と、成立後の出来事を分けて残す

一輪の入口では、要求 F と過去の認証済み状態が束縛される。現在の補正とsourceが生成する内部未来境界での成立を同時に満たすようsourceを選び、そのsourceを下位で実行・認証・公開する。その後、指定headと同階層在庫から成立する語を照合し、一つを確定して実行する。

従って未来要求は、完了したログの分類にだけ使われるのではなく、**実行前のsourceと履歴の許容条件として残っている**。一方、候補の計算結果はまだ出来事ではない。実際の順序付き実行と既存Decoderの認証を経たものだけが完了記録になる。

この手続きを前向きに計算できることは、結果を拘束の基準に据えた計算原理を取り消さない。同時に、source・境界読出し・候補範囲・自由な選択値は明示した模型条件であり、これらを未来因果から一意に導出したとはしていない。

## 3. 保存記録から現在へ作用する最小インターフェース

四つの入力は、RR52 v001で公開した二枝×二選択の `examples/*.record.json` そのものである。実験をやり直して似た履歴を作るのではなく、そのexact object graphを読み戻す。

1. `import_record` が、外から渡した入口設定に対して生成・選択・実行・認証を照合する。
2. `read_retained(record, receipt, reference)` は、信頼した不変な確定記録に対して、実際の完了記録・固定要求・継承・残差を再照合する。
3. 保存されたlevel 3の終端作用 `terminal_operation.execute` を、同階層の参照状態 `(Y,q)` に適用する。

終端作用の入れ子の語を β、文脈依存kernelを Kβ(Y) とすると、現在の参照状態は

$$q_{\rm after}=K_\beta(Y)q$$

へ変わる。出力は履歴名や選択番号の比較ではなく、既存の作用そのものによる状態更新である。参照のために元の完了状態、在庫、出来事列、終点を変更しない。

読出し時は、根のsolver・候補探索・元の `run_flower`・入口再生成を禁止しても通る。一度目のファイル検証には入口・選択の再検証が含まれる。この二段階を混同しない。また、確定記録は外部の信頼基点であって、作者の身元を保証する暗号署名ではない。

## 4. 同じ要求に閉じた二履歴の差を、何で読むか

基準模型では短い語が head→source、遠回りが head→head→source→source になる。原始作用を増やさず、どちらも同じ固定要求と誤差基準を満たす。

対角文脈では各因子が実数なので、P(Y)=Ksource(Y)Khead(Y) とすれば、保存された短い終端作用はP、遠回りはP²として働く。今回の証人は語長・反復回数も異なる二履歴であり、全ての順序差をこの参照で識別する命題ではない。

| 参照条件・q=1 | 第一枝：短い語 / 遠回り | 第二枝：短い語 / 遠回り |
|---|---:|---:|
| 元の現在補正文脈でのraw応答 | 1 / 1（exact） | 1 / 1（exact） |
| 変更した参照中心でのraw応答 | 約12.750768 / 162.582089 | 約59.999815 / 3599.977841 |
| 閉鎖文脈で、actual倍率を除いた応答 | 1 / 1（exact） | 1 / 1（exact） |
| 変更した参照中心で、actual倍率を除いた応答 | 約12.750768 / 162.582089 | 約59.999815 / 3599.977841 |

変更した参照中心は Y*=diag(3/2,1/4,−3/4)。元のheadの認証入口にも現れる条件だが、今回の読み取りでは保存した終端作用に対する新しい参照入力として与える。元の一輪の文脈を遡って差し替える処理ではない。

actual倍率とは、各終端作用が実際の閉鎖点で持つ可視倍率 vβ のこと。微小な終点誤差だけで差が出たという説明を切り分けるため、診断上の読出し

$$\widehat q_\beta(Y)=v_\beta^{-1}K_\beta(Y)q$$

も併記した。これは読出し規約であり、保存終点を−1へ丸めたり、認証された作用を書き換えたりしていない。可視倍率だけを用いた対照なら vβ⁻¹(vβq)=q となり、二履歴の区別は消える。完全な入れ子の作用では、変更した参照条件で差が残る。

逆に、現在補正文脈のraw応答、閉鎖文脈の倍率除去後の応答、q=0の応答では差が見えない。**必要なのは差を読める作用の存在と持続であり、全ての参照が全履歴を識別することではない。**

## 5. 参照条件を変えても、一律には消えない

Y*の対角成分を(c₁,c₂,c₃)として

$$Y(d_1,d_2)=\operatorname{diag}(c_1+d_1,c_2+d_2,c_3-d_1-d_2),\qquad |d_1|,|d_2|\le10^{-6}$$

を取る。これはtrace 1を保つ、二つの独立な参照自由度である。

保存された各原始affine文字は最初の三軸sourceのみを使う。対角文脈での応答は `2 Σ wᵢ yᵢ − 1` なので、その積を有理区間演算で評価した。軸sourceの認証終点を確認してからこの式を使い、実際の保存kernelとのexact照合も行った。対角成分の相互差も範囲全体で0を避け、既存六生成libraryのregularなチャートに留まる。

範囲全体の「遠回り−短い語」の倍率除去後の応答差は、第一枝で絶対値149.8285超、第二枝で3539.9319超。raw応答差も0を避ける。正確な有理数の上下界は `retrospective_residue_readout_result.json` に保存した。

これは隅の試算からの一般化ではなく、この参照範囲全体の区間証明である。補助的に二枝×四隅の8入力では、q=(1,2,−1,3)という新しい現在値も実際に更新し、二履歴の応答差を確認した。

保証したのは、同じ四つの保存記録に対する、対角実数応答クラス内の参照の変化である。任意の文脈変形・source変形・全履歴についての識別定理には広げない。

## 8. 一輪の完成範囲と残す問い

**今回の指示書に沿う、条件を明示した一輪の最小模型として完成に置ける。** 実行前の未来要求が現在の許容運動を拘束し、一つの履歴が実際に成立し、その成立に由来する差が後の参照状態へ再び作用するところまで計算できた。

source生成則や選択則の唯一の原理的導出、隣接フラワーへの実際の接続、上位拘束による実効的一意性、位相転換での区画再編成は、今回の一輪を完成させるための追加要件にはしない。一意性・非一意性のどちらも全階層の公理に固定しない。**局所的な非一意性は、マクロの非一意性を意味しない。**

今回の保持は完全な履歴の保持であり、過去状態を捨てた後に最小限の残差だけで同じことができる、という圧縮定理ではない。主観体験、感情、変態そのもの、物理的な逆時間作用の証明もここには加えない。これらの可能性を定義で排除するものでもない。

完了した一輪が連続稼働しなくても、この模型では完了である。今回の新しい到達点は、その停止が「運動の差の消滅」にはならず、後の作用に使える形で残ることを具体的に検査できた点にある。
