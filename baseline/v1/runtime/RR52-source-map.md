# RR52 — 一輪v1の原本対応と完成範囲

原本v18 rev.5：固定取得元1450f74d628b214d6cb19a95d8f9a184b6e35aec、SHA-256 788cd5e7ce984bd450ec443a2e86ebdc2926bf139e38bc7f4929cc4bc5f05e1f。参照抜粋v18-rr47-source-excerpts.md、v18-rr51-selection-gaps.md。

| 働き | 一輪v1の対応 | 条件・範囲 |
|---|---|---|
| CG1の二境界適合 | 現在の補正と内部未来文脈での成立を満たすsourceを生成し、全語の成立候補を検査 | 生成則・読出し方・根の枝は宣言した模型条件 |
| §7の結果に適合する履歴の選択 | 成立する全語から入口の自由な値で一つを確定 | 唯一の選択原理の導出や最短化は要求しない |
| 第一境界のDecoder | 確定した語を実行し、exact終点を既存Decoderで認証 | 固定Fとの近似誤差は別に検証し、終点を改変しない |
| CG5・§15のfull residue | sourceと終端セルの完全な入れ子の認証・実行語を保持し、JSONから同一に復元 | 情報を消す圧縮や次のフラワーの実行とはしない |
| RR43のsource実行・公開 | 実行・認証・公開の後に内部文脈を生成 | 未実行の補正値や可能な候補を在庫へ追加しない |
| RR47監査の入口照合 | 固定F、継承値、source、公開記録、prefix、語、順序を束縛して拒否検査 | 不変な確定記録／入口設定を信頼基点とする整合性検証 |
| RR51の局所選択反例 | 全語で成立を検査してから確定し、実行中は選び直さない | 実時間のD単調性は要らず、遠回りも許容する |
| アキの2026-10-16指示 | 一輪の花びらの自由を残し、局所非一意をマクロ非一意へ外挿しない | マクロの拘束・一意な搬送は次段階 |

一輪の実行・認証・保持・停止の手続きを、この条件内で完了した。source生成則・選択規則の唯一の原理的導出、実際の隣接セルの外部残差評価、複数フラワー接続は今回の完成範囲に含めない。
