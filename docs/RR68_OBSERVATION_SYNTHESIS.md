# RR68 — 要求の式から、十分な観測を構成する

2026-10-23。RR67固定版`84f3425aecdda16903ab925f4c348fe519b87f71`からの追加。

**積・和・語別の重み付き和という候補を渡さず、要求が使う式から低次数の観測を構成し、全作用と判定を再現する保証を付けて実行へ渡した。**

RR66/67の候補選択から、観測の式自体の構成へ一歩進める。今回使う物理模型・source族・接続則は既存の二輪模型のまま。未知の物理法則や接続則を発見した成果とは区別する。

## 1. 発見器が受け取るもの

入力は、固定した要求・現在係数・現在語についての全13作用・guard多項式と、形式変数名、有限な作業予算だけ。

発見器`observation_synthesis.py`は、source幾何、語、primitive位置、旧観測のカタログ、保持値を受け取らない。`p=st`や`7s+8t`を候補として渡さない。現在のsourceを実行して成功経路を作る必要もない。

発見器の外側では、RR67の既存算術グラフから要求の13式を作る。従って、観測構成は候補なしで行うが、元の運動方程式まで未知という設定ではない。

## 2. 次数ごとの線形代数で構成する

各要求多項式を、同じ次数の項に分ける。

1. 既に得た観測の積で、その次数を作れる組合せを列挙する。
2. 完全な有理係数を使う消去法で、要求の同次成分をその空間へ還元する。
3. 残りが非零なら、その低次数の残りを正規化し、新しい観測とする。
4. 全ての次数について表現を作り、元の多項式を再構成する。

観測数は最大2、各観測の次数は最大2。入力次数は最大16、項数と次数ごとの生成積数にも上限を置く。式が予算を超えれば未解決として止める。要求式を丸ごと一つの観測へ名前替えして、何でも成功した扱いにはしない。

同次成分に分けることで、元の要求が必要とする以上の情報を選ぶ場合もある。これは有界な構成方法であり、あらゆる十分統計や全ての有理関数を探索した最小観測の定理ではない。

## 3. 保証

構成した観測をφ₁,…,φₖとし、各要求多項式をfⱼとする。全てについて

\[
f_j(z)=\widehat f_j(\phi_1(z),\ldots,\phi_k(z))
\]

を、有理係数のまま再展開して全係数照合する。

消去法の各行は、元の多項式と観測側の式の対応を保持する。既存の生成積で表せる行は、その対応を使う。新しい残りを観測にした行では、その残りと新変数を対応させる。この操作を次数順に続ければ、最後の全再展開が元の式と一致する。

同じ観測値を持つ二状態は、固定した要求内の全13式で同じ値を持つ。分母・chart・資源範囲などを元と同じ条件で判定し、許可された場合に同じ新作用T/Rを得る。αだけ、または数点の成功だけを照合した近似ではない。

元の状態や履歴全体を同一視する保証ではない。新しい要求へ移れば、別の観測が必要になり得る。元の差を保持する原則はそのまま使う。

## 4. 出てきた観測

混合C・接続強度0では、積を入力候補に与えずに

\[
g_0=st
\]

を構成できた。定数項と個別の一次項が消えていても、二次の混合項から観測を取り出せる。

同じ物理状態を

\[
x=s+t,\qquad y=s-t
\]

で表し直すと、要求式から

\[
g_0=x^2-y^2
\]

が出る。名前を見て積を選ぶ処理ではない。実行へ渡すときは元のs,tの座標へ厳密に戻し、もう一度全13式を照合する。

非零接続の要求では、必要な一次の組合せも出る。元の座標では、例えば

\[
g_0=s+\frac87t,\qquad g_1=st
\]

となり、語を替えれば係数も変わる。mainのCでは、独立な二つの一次観測が必要になる場合も構成できる。常に一観測へ押し込む機構ではない。

split座標の非零接続では、構成した観測を元のs,tへ戻して正規化すると、例えば

\[
z=s+\frac87t,\qquad q=s^2-\frac{113}{49}st+\frac{64}{49}t^2
\]

になる。qは旧カタログの項目ではない。この観測を実際に登録・使用して閉鎖した。既に積とzを読んでいれば、`q=z²−(225/49)st`からも導ける。新しい表現を構成した成果であり、既知の情報より多くの情報を無から得たという意味ではない。

座標変更は同じTE模型の表示を変える対照であり、新しい物理接続の成功例には数えない。別に、未登録の一次形式`3x+5y`と二次形式`2x²−xy+7y²`から作った多項式群でも構成・全再展開を検査する。この例は純粋な代数診断であり、実際のTE在庫へ新しい過去を発行したとはしない。

## 5. 構成と、数値の登録・読出しを分ける

観測の形を作る段階では、元のs,tや派生値を読まない。構成後、観測の定義・由来・認証済み元値の範囲を結びつける。

値が必要になったときは次の順で扱う。

- 既読の観測から新しい定義を表現できれば、その恒等式を再展開して確認し、既読値から導く。
- 初めて数値化する観測は、必要な元の保持値を明示的に読み、定義どおりに計算してVaultへ登録する。
- 登録された観測値の抽出と、登録のための元値読出しを別に数える。合計のexact query数も保存する。

例えば初回の積の登録にはs,tの2読出しと、観測値の1読出し、合計3回が必要だった。登録済みの旧カタログから積だけを読む従来方式より、初回の処理を安くした成果ではない。

`unregistered-split`列では、接続強度0で得た二次観測を保持し、非零接続へ移った後、新しい一次観測を1個登録・読出しする。その後に必要な二次観測は、既読の関係から導けた。後者のための元値の追加読出しはない。作業記録には新規抽出・登録用の元値読出し・既読値からの導出を分けて残す。

作業記録の`newly_registered`は元値から初回数値化した観測を示す。既読値から導いて登録した観測は`derived_features`と読出し履歴の`derived_keys`へ分ける。

旧s,t,pと旧派生観測は完全に保存する。旧カタログは発見器にも数値抽出にも使わないが、過去の記録から消さない。新たな観測は別のVaultへ登録する。元の数を丸める精度配分や、全体の高速化は今回の達成条件ではない。

## 6. 実行と保存再開

構成済みの観測から全作用係数を求め、現在が選んだ語で、既存の下位生成・認証・公開・Decoderを使う。元の過去二輪と在庫を継承し、今回の二輪と上位セルを閉じて停止する。在庫は6→7→8。

要求・座標・予算を変更したら、古い準備済み作用は失効させる。新しい観測保証と値を使って選択・精査し直す。二輪の実行開始後に未来要求を変更する機能は今回追加していない。

動的に構成された観測も、元の要求列から再構成できる。保存記録には、完全な元数、未使用の旧派生観測、その時点の履歴で取得した新観測、時系列・実運動を含める。後から別のセッションが作った観測を、古い時点の保存へ混ぜない。

外部で保持したSHA-256、認証済み入口、元の初期要求・座標を照合し、再演した観測の定義・値・実運動まで確認する。保存後の新規登録費用は、既に温まったVaultかどうかで変わり得るため、再開時に同じ物理結果と読出し・導出の履歴を求め、同じ登録費用までは要求しない。

## 8. 残る境界

この方法は同次成分から生成元を加える有界な構成である。例えば`x²,xy,y²`の三式では、今回の方針では二次観測を3個必要とし、予算2なら未解決になる。元のx,yをそのまま読めば二観測で足りることと矛盾しない。全ての十分な表現を探索する完全なアルゴリズムではない。

未知の接続則の発見、任意次数の最適観測、原変数の精度の自律配分、無限の保持量制御、Cの自律生成までを完成としない。今回の一歩は、**固定候補の選択を越え、要求の式から観測を構成し、その適用範囲を証明して実運動へ渡せたこと**である。

## 9. 動かす

Python 3.10以降、標準ライブラリのみ。

```sh
python run_synthesis.py inspect --context mixed --strength 0 --frame split
python run_synthesis.py demo --out-dir .work/synthesis-demo
python integrations/inquiry/validate_synthesis.py
```

`inspect`は観測の構成で止まる。入口の過去の認証と旧観測の登録は別に行うが、発見のための元値読出しと今回の二輪実行は行わない。`demo`は要求更新列を段階保存し、最後に正常停止する。既存ディレクトリを上書きしない。

`start`、`choose`、`resolve`、`revise`、`execute`、`verify`でも操作できる。読込には外部で保持したハッシュを指定し、初期要求が既定のmixed・強度0・identity以外なら、`--initial-context`、`--initial-strength`、`--initial-frame`も指定する。
