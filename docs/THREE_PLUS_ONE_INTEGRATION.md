# 3+1を内蔵したTime Engineの強化

2026-10-18。**3+1独立模型は完成した部品として扱う。強化する対象は、それを組み込んだTime Engine。**

[RR58](RR58_DEFERRED_RESIDUE.md)では、自由数CoreのB₂応答を用い、[保持と置換の基本原則](PRINCIPLES.md)を実装した。置換可能性の判定と消去を分離し、指定範囲での展開省略と、後の範囲での再展開を検査する。22件の固定した一輪・三輪読出しで厳密版と一致。128継続族全体の再列挙や、actual認証の近似化は行わない。

[RR57](RR57_EMBEDDED_THREE_FLOWER.md)では、局所で全8候補が同じ結果へ閉じる条件を置き、保持された作用差を既存の第二・第三輪へ通す。共通上位要求によって第一輪の許容候補が、保持時一つ／消去時四つになることを検査する。各第一候補について後続16通りを比較する。

「局所的な非一意性は、マクロの非一意性を意味しない」を、3+1を組み込んだTEで検査する。00相対校正付き部分写像、宣言した可解fixture、有限継続族という条件は引き継ぐ。認証済み履歴の保持と、次の文脈への変換、新sourceの実行・認証・公開を分ける。

TEの終端から神経状態へ戻す新しい更新則や、各輪で神経接触を繰り返す機構は、この検査の必要条件には置かない。完成した3+1の再完成を、TE強化の合格条件に加えない。

## 最初に確かめること

**同じ現在の読み取り・同じ未来要求でも、3+1の保持差を残す場合と消す場合で、一輪の許容候補が変わるか。**

3+1の基準版は[知性の最小モデル v1](https://github.com/residual-chart-lab/three-plus-one/blob/b6daea3801504ddfa34b0a26d8e86ade94d06e06/docs/INTELLIGENCE_MINIMAL_V1.md)。基準ネットワークの17パラメータを含む運動を扱い、その上の三保持方向＋一位相という局所分解を引き継ぐ。四個の数だけの自律系として取り出さない。

## 一つずつ接続する

1. 3+1の状態・保持差から一輪入口への受け渡し写像を先に固定し、既存作用との対応と追加仮定を明記する。結果に合わせて写像を調整しない。
2. 現在の読み取り、未来要求、候補群、許容誤差を揃え、保持差あり／消去で許容集合を比較する。3+1側で読み取りを保つ消去が、受け渡し先でも比較条件を保つか確認する。
3. 許容された候補が実際に実行・認証され、一輪として完了するか確かめる。
4. 往路の成立後に、Time Engineで残った差を次の3+1の応答へ戻す復路を検査する。

教師値とCは役割を分ける。差の大きさやラベルだけで適合性を決めず、作用値に基づいて比較する。接続できなければ不足した構造を記録する。

まず一輪への往路を対象とし、三輪全体との統合や復路の完成を先取りしない。三輪接続模型v1の固定物はそのまま残す。

## RR56でできたことと、条件

既存の保持差の非一様応答成分を、00接触との相対差として現在作用のnull方向へ運ぶ写像を固定した。全17基準パラメータと局所運搬も保持する。同じ四接触と写像、現在位相、TE現在応答、未来文脈、F、εの下で、保持一候補／消去四候補を確認。共通なのは四つの接触と生成則であり、保持差から生成されるTE source係数自体は変わる。

これは基準接触を通す校正を含む部分チャネル。全三保持方向の単射輸送ではない。消去時にはTE係数は一種類へ写るため、四つの異なるTE sourceが通るという意味でもない。実際の3+1更新としては四接触が区別される。

今回の受け取り口は共通の固定未来文脈を到来させる。RR46・52のように候補ごとのsourceから未来文脈を生成し直す条件とは分ける。各原版は変更せず、追加した接続条件と対照を[本文](RR56_THREE_PLUS_ONE_OUTBOUND.md)へ記録した。
