# RR65 — 自由数の混合残差を、束の作用集合へ接続する

2026-10-21開始、2026-10-22確定。RR64固定版 `b3dd0263d71e7284d6ca59875476d893c13f71ac` からの追加。

**ある保持差を省略しても、束を成立させる実作用の集合が保存されるか。** この問いを、自由数の混合多項式・実行前の判定・実際の二輪へ直接つないだ。

主な結果は二つある。

1. 二つの保持差が単独では見えず、積になって初めて束を成立可能にする例がある。片方を消すと作用集合は空になる。保持・復元では実際に束が成立し、消去では両輪が局所閉鎖しても束は成立しない。
2. 条件を限定すると、個々の厳密値を読まず、保持した積だけで、全く同じ新作用の全係数を生成できる。元の二つの差は残す。接続条件を変えると個別情報が再び必要になる。

未来因果はTEの設計前提として保持する。今回は、その前提で必要な「何を省略でき、何を実行前に読まねばならないか」の演算を強化する。

## 1. 判定する作用集合

要求C、既存在庫、接続則、補正の資源範囲、現在候補を先に固定する。

今回の問いPは、**現在の語の指示、新しく生成するTの全係数、新しく生成するRの全係数**を観測する。補正係数αだけの一致では十分としない。現在候補はv=−64,0,1,64と二つの語の8候補。任意の操作列全体についての集合とはしない。

各候補の実作用集合は、認証可能で資源範囲内なら一つの物理的な(T,R)、不成立なら空、保証できない場合は未解決となる。語は、既存の保持sourceを役割S,Uとして使用する指示である。保持source自体は状態入力として受け継ぐ。

保持差の省略は、比較する式の中で指定座標を代表値0に置くことを指す。この比較だけで、Vaultや実際の履歴は変更しない。

- 両方空なら、依存項があっても、その範囲では作用集合は同じ。
- 両方成立可能なら、物理的な全係数が同じかを比較する。
- 一方だけ成立する、または物理的な係数が異なるなら、作用集合は異なる。
- どちらかを保証できない場合は未解決。省略許可にはしない。

## 2. 二つの保持差を同じ実在庫へ入れる

既存RR60のcontact 1とcontact 2から、独立の由来を持つ保持スカラーs,tを受け取る。3+1やその固定写像は変更しない。

同じ現在文脈Y0=diag(1/3,2/3,0)で、

\[
S=X_*+s\Delta,\quad U=X_*+t\Delta,\quad T=X_*+v\Delta,
\qquad\Delta=\operatorname{diag}(-2,1,1)
\]

とする。Sは元の認証済み実source。Uは、第二の保持記録から係数を取り出して同じ下位実行器で生成し、認証・公開し、一つの過去のHUを実際に閉じてから今回の入口にする。別履歴の操作を在庫へ無断で挿入しない。

元の一輪＋Uの準備用一輪が過去にあり、その後に今回の二輪を実行する。在庫は入口6→7→8、round数は2→3→4。元の累積値、出力、時系列はそのまま継承する。

入口は`register`が認証して発行する。digestだけをコピーして下位の継承値を差し替えた入口は受け付けない。照会ごとに保持係数や履歴全体を再展開せず、発行済みの入口との対応を確認する。

H(Y0)=−1/9、S(Y0)=U(Y0)=T(Y0)=−9なので、現在語は

```text
HHHSUT または HHHUST
```

とする。H³と三つのsourceの積は1になり、実際の−1から−1へ初回閉鎖する。primitive展開は9葉、RR53の順序重みはk/45。二輪目は従来のHR、実際の出口をRR53で読んだ文脈を使う。

## 3. 混合残差が、作用集合の有無へ直接効く

対角Cについて、TEのprimitive応答をJ_C(X)と書く。混合項を分離する対照では、Cを次の規則で計算前に固定した。

\[
c_0=1/4,\quad\operatorname{tr}(X_*C)=1/2,\quad
c_0+c_1+c_2=1.
\]

X*は既に固定された現在の代表source。成功経路からCを作ってはいない。この規則でJ_C(X*)=0、J_C(Δ)=1/2、H(C)≠0となる。

第一輪の出力のCでの応答は

\[
B_1=H(C)^3J_C(S)J_C(U)J_C(T)
   =H(C)^3\frac{v}{8}\,st.
\]

したがって、代表点s=t=0では定数項・sの一次項・tの一次項がすべて0であり、**単独の一次感度だけを見る対照は、残ったst項を落とす。** これはB1の一次近似についての対照であり、極にある補正式のJacobianを定義したという主張ではない。

二輪を束ねた終点は、実際の継承値−1から

\[
q=-H(C)B_1\{J_C(R_0)+\alpha J_C(\Delta_2)\}.
\]

一方でも消すとB1=0となり、どんな有限のαでもq=0。要求+1へ届く作用はない。両方を保持した場合は、指定範囲内の補正を実行前に求め、実際に二輪・上位セルを閉じられた。

主入力の補正範囲はあらかじめ[−10^40,10^40]とした。混合対照は大きい補正を必要とする。係数が小さく扱いやすいことや、長期安定稼働の実験とはしない。

## 4. αだけでなく、実作用全体の等価性を判定する

RR64と同じ二輪の引戻しからα=N/Dを作る。実際の二輪目のsourceは

\[
R=R_0(Y_2)+\alpha\Delta_2(Y_2)
\]

なので、αが同じでもY2が変わればRは変わり得る。

そこでh=H(Y2)、d=y0−y1、a0=1+h(1−2y1)として、Rの各座標を共通分母Lで表す。

\[
L=2hdD,
\]
\[
J_0=a_0D+2hN(y_1-y_2),
\quad J_1=(2hd-a_0)D+2hN(y_2-y_0),
\quad J_2=2hdN.
\]

物理的なRの係数は(J0/L,J1/L,J2/L,0,0,0)。これらの多項式は自由数runtimeで混合項・反復項・相殺を保って構成する。

省略写像πについて、分母とchartが保証された場合の等価性は

\[
W_i=J_i(s,t)L(\pi(s,t))-J_i(\pi(s,t))L(s,t)=0
\quad(i=0,1,2)
\]

で判定する。零多項式ならその範囲で全係数が一致する。実際の保持値を含む区間でWiが0から分離できれば、作用が異なる証人になる。区間を有限に精細化しても決まらなければ未解決とし、勝手に同一視しない。

存在しない作用同士の比較、資源区間、分母の極、現在の正則性、初回境界、下位sourceの活動性を別に確認する。係数の見かけの依存だけでは省略可否を決めない。

## 5. 個々の展開を省き、混合量だけを残す

主入力のoffdiagonal対照は、現在のsource閉鎖条件を満たさず、入口で拒否された。対角境界では非対角差が必ず見えないという仮定は、このTE応答では使えなかった。記録に残し、成功件数へ数えない。

その後の追加診断として、混合Cと結合強度0の既存ケースを調べた。この範囲では、作用とguardを構成する全多項式の各単項式がs^n t^nという形になる。よって

\[
p=st,\qquad s^nt^n\mapsto p^n
\]

という厳密な対応で、**作用集合と成立判定を保存できる。** 単にB1だけを保存した近似ではない。

pは登録時に元のs,tから一度厳密に計算して認証する派生観測である。無料で得られる値とはしない。Vaultにはs,t,pをすべて保持し、各由来とp=stの関係を結ぶ。

pを登録する選択は、今回の設計条件である。未知の模型について、保存すべき混合観測を自律的に選び出す機構までは導出していない。

8候補中、v=0の両語は空、残り6候補は成立可能。個別読出しではs,tを各6回、計12回読む。同じ物理的作用集合を、pだけの計6回の厳密読出しで再現できた。個々のs,tの厳密読出しは0回。登録・実行・保存・対照計算の厳密演算は別であり、全体の高速化率ではない。

結合強度を1/1024へ変えると、実際のRR53文脈に個別のs,tが現れる。全式をpだけへ写す証明は成立しなくなり、共同観測だけでの実行を拒否する。元のs,tを保持しているので、必要になった個別情報を読み直せる。

## 6. 検証と不成立の扱い

主入力は[事前コミットa7ea44b](https://github.com/residual-chart-lab/time-engine/commit/a7ea44bf2e25915a54087f28cc76bf90f4e8b1df)。公開バイトの読戻しも一致した。SHA-256は `4b738ebfc55046bef793ac4ed98947e372a438ef232f8b148b1f39f8ada08abd`。

- 有効な24スコープ、計192候補比較が、別の厳密行列構成・affine補正計算と一致。結果はDIFFERENT 12、SAME 6、UNDETERMINED 6。未解決を成功や省略許可に変えない。
- 比較段階のs,tの厳密読出しは0回。区間の精細化は使用し、件数を別に記録する。
- offdiagonalの一構成は入口拒否。予定した12スコープと追加実行2件は適用不能として残す。
- 実際の運動は9組。保持・復元・混合観測・両語を含む5組が上位認証に成功。残り4組は明示した負対照で、両輪の局所閉鎖を保っても束は成立しない。
- 元の差を消去せず、混合観測から実行した完全記録を保存し、入口・要求・現在選択・s,t,p・在庫・累積値・時系列を厳密再実行で照合する。

主入力のoffdiagonal失敗を、後から別の成功例へ置き換えてはいない。混合観測pの診断は追加探索として区別する。結果・検査件数・ソースハッシュは [RR65-validation.json](../integrations/inquiry/RR65-validation.json)、全記録は同じディレクトリのRR65ファイル群に保存する。

## 7. 実行

Python 3.10以降、標準ライブラリのみ。リポジトリ直下から：

```sh
python run_mixed.py inspect --context mixed --omit t
python run_mixed.py inspect --context mixed --strength 0 --joint
python run_mixed.py run --context mixed --strength 0 --joint --out .work/mixed.json
python run_mixed.py verify --context mixed --strength 0 --joint --v 1 --word HHHSUT --record .work/mixed.json --sha256 <返された値>
python integrations/inquiry/validate_mixed.py
```

`inspect`は登録後の二輪を実行せずに停止する。入口のU準備用閉鎖は登録時に既に行う。`run`は指定した二輪と上位セルで停止する。省略証がDIFFERENTまたは未解決なら、その省略での実行を許可しない。実験専用の負対照はCLIに公開せず、成功した完了記録にもできない。

検証の新しい出力は`.work/rr65-local/`。旧RR64の実装・自由数vendor・結果は固定し、案内文書以外の295ファイルを照合する。RR64の段階実行や元の三輪模型を置き換える工程ではない。
