# RR58 — 置換可能性の保証と、残差を消さない演算

2026-10-18。完成した3+1を内蔵するTime Engineへ、自由数のB₂応答と、範囲を指定した読出し省略を接続する。

## 基本原則

**置換可能性は、差を保持したまま、指定された演算範囲でその展開を省略できる保証である。**

これは[TEの基本原則](PRINCIPLES.md)へ記録した。判定と消去を分離し、後続で必要になった差を再び読めることを合格条件にする。

## 1. 自由数Coreから使うもの

基準はFree Numbers Core v1.0.0の固定コミット`9efc241d38e5ca2cd07f425b747bfb5d67ea0235`。[Length-Two Exact Splitting](https://github.com/residual-chart-lab/free-number-core/blob/9efc241d38e5ca2cd07f425b747bfb5d67ea0235/core/04-length-two-exact-splitting.md)とMIT LICENSEを改変せず同梱し、Git blob SHAとSHA-256を照合する。

\[
B_2\cong\mathbb H\oplus S^2_0V,\qquad
x=\sigma_2(m_2(x))+\rho_2(x),\qquad
A_2(\rho_2(x))=-2C_{\rho_2(x)}.
\]

既存TEのprimitive `AffineLetter`を、その認証済みライブラリ境界の重み付き和Xへ写す。実装したσ₂の符号はCoreの`m₂(e_a|e_b)=e_b e_a`に合わせる。9基底の分解・再構成と27の基底probeを検査し、実際のTEで`join(X,Y)`が元の作用kernelに一致することを8件で照合した。

**ここでm₂(X)=−1であることと、昇格済みTE sourceのvisible作用が−9であることは、異なる読出しである。** この二つを混同しない。B₂はprimitive境界の座標として使い、高階層の作用は元の順序付き語のまま保持する。全gradeの自由数decoderや新しい自由数の乗法則を実装したとはしない。

## 2. 差を展開せずに保証できる例

RR56・57から引き継いだsourceの係数を

\[
\lambda=\lambda_*+s\delta
\]

とする。固定文脈Yでの作用差は

\[
K_\lambda(Y)-K_{\lambda_*}(Y)
=sG(Y),\qquad G(Y)=\sum_k\delta_kK_k(Y).
\]

現在文脈ではG(Y)=0を、小さいライブラリとδの計算だけで保証できる。大きな有理係数のsを作用応答へ展開せず、代表sourceと同じ応答を返せる。一方、元の係数・s・δ・認証元は保持する。入力時には、元の係数がこの式に合うことをexactに照合する。

判定証は対象のdigest、入口、観測、文脈の族、検査予算、応答因子へ束縛する。圧縮値・kernel・境界テンソルという観測を区別する。

元の完全な三輪記録は変更せずに保持し、読出し表現の認証元として参照する。primitiveの係数・ライブラリは式にも残す。新しい判定証は作者の署名や、元記録の独立な再実験を代替するものではない。

- 現在文脈だけのΓ₁では、四接触全てを置換可能と認証できる。
- 現在と後の文脈を含むΓ₂では、現在しか調べない予算なら未判定。後の文脈まで調べると、非零の保持差は置換不可能になる。
- Γ₁の判定証はΓ₁の保証として残り、Γ₂や境界テンソル読出しへは流用できない。

後の読出しでは元のsource応答を再計算し、厳密版と一致する。さらに固定した後続作用を順序付きで追加しても、再展開した応答が元の非可換な積と一致することを検査した。

これは固定文脈での作用読出しの保証である。RR53が元の境界や順序を読んで次の文脈を作る処理には、その観測の保証が別に要る。現在のkernelが同じという理由で、接続入力やactual在庫を代表へ置換しない。

## 3. 小ささによる消去をしない対照

係数差s=10⁻²⁰を持つ同じ型のprimitiveを作る。現在では不可視だが、許されたregularな文脈`diag(10²⁰,1−10²⁰,0)`では作用差のL₁ノルムが1を超える。逆にs=10⁵⁰でも現在文脈では応答差が0で、展開を省略できる。

これはprimitive B₂チャートでの対照。新しい作用を同階層のactual在庫に公開した試験や、RR48の局所パラメータ箱での安定性定理としては数えない。差の大きさと、指定範囲での置換可能性が異なることを示す。

## 4. 必要な精度だけで候補応答を読む

もう一つのフィルターは、保存された語と入口を変更せず、作用応答を外向き区間で評価する。格子は

\[
[L2^{-p},U2^{-p}]
\]

で、全ての乗算を外側へ丸める。pは二進小数部の格子精度であり、整数全体のビット長や浮動小数の仮数長とは異なる。保持された有理数から整数除算で境界を取り、区間内部の演算には固定格子の整数を用いる。

最終誤差の上限がε/2未満、全ての途中誤差の下限がεより大なら合格。最終誤差の下限がε/2以上、または途中誤差の上限がε以下なら不合格。どちらも保証できなければ未判定とし、24→48→80→112の事前に固定した順で精度を上げる。予算終了時の未判定を合格へ丸めない。

判定証には元の語の順序、各上位作用のまとまり、文脈、継承値、要求、ε、認証元を束縛する。途中の境界を無視して最後だけを比較しない。これは合否読出しの証明であり、実際の終点やDecoderセルの認証ではない。

## 5. 検証した範囲

- RR57の四接触×二語を、現在と後の二文脈で読む16件。
- 保存済みの実際の三輪記録3件を、共通上位の基準・別文脈で読む6件。
- 合計22件で、元の厳密TE演算と合否が一致し、全ての途中誤差も区間に入る。
- 20件をp=48、残り2件をp=80で確定した。
- この22件の評価では、元の厳密なleaf応答の展開が基準計算126回に対してフィルター0回。小さいライブラリの応答、係数境界の整数除算、入力のexactな照合は別に必要である。
- 同じ環境の時間も診断値として記録する。入力認証やsource生成、実際の閉鎖認証を含むTE全体の高速化率としては使わない。

主10検査群、新22＋既存のDecoder・source公開14＝36テスト。偽造した判定証、観測・入口・境界・許容誤差・継承値・語のまとまりの差し替え、厳密閾値での誤合格、低精度の未判定を検査する。区間証明を既存のセル昇格へ渡しても受理されない。

RR57の128継続族全体や元の252テストを今回再実行したとは数えない。入力の実際の三輪記録は、信頼したハッシュへ照合し、TEのexact再実行と元bytesへの再出力で確認した。3+1のSGDやsourceの根は再生成しない。

## 6. 到達点

**指定範囲では差を展開せずに済ませ、後の範囲では保持した差を再び使う。その間の運動も順序付きで保持する。** 自由数のB₂構造を用いた最初の読出し実装として成立した。

元の履歴の完全保存、RR56・57の接続条件、actual在庫、F・ε、実際の認証は保つ。保存量削減、全gradeでの最小表現、あらゆる未来に対する自動判定、source生成や全探索の精度配分まで完成したとはしない。
