# RR57 — 3+1を内蔵したTime Engineの三輪拘束

2026-10-18。3+1独立模型は完成した部品として受け取り、RR56で実装した保持差の写像を使う。今回強化する対象はTime Engineである。

## 問うこと

**現在の読み取りも第一輪の結果も同じで、局所では全候補が成立する。それでも、保持された差が第二・第三輪との接続を通り、共通の上位要求によって第一輪の選択肢を変えるか。**

RR56では共通の局所未来文脈で、保持一接触／消去四接触になった。今回は局所での選別を意図的に外し、差が後続接続と上位条件まで届くことを検査する。独立した3+1を作り直す工程ではない。

## 入口と固定条件

- 入力はRR56の公開済み記録。元の三記録とマニフェストのハッシュを照合し、保存された17パラメータ、九時点の運搬履歴、接空間、保持差を受け取る。入口を用意するためにSGD・J・Kやcarrierの根を再生成しない。
- 写像はRR56のまま、`s_x=γ(u_x−u_00)`、`λ_x=λ*+s_xδ`。00相対校正と部分チャネルという条件も引き継ぐ。γ=1、対照は0。
- 第一輪の共通の閉鎖文脈には、carrierの現在文脈をそのまま用いる。δが不可視な文脈であり、全接触のsource応答はexactに−9。これは新しく宣言した局所fixtureで、RR46・52の候補ごとのsource生成境界と同一視しない。
- 第一輪の語は、既存の短い語`head,source`と迂回語`head,head,source,source`。四接触との積で八候補。どれも途中では閉じず、終点−1へexactに閉じる。
- 第二・第三輪はRR53の既存の順序付き終端読出しとanchored接続（強度1/1024）、RR54の二source枝×二語を使う。第一輪の各候補に後続16通り、合計128通りを計算する。
- 共通上位文脈はRR54と同じ`diag(x,1−x,0)`、`1/4<x<2/5`。第一輪00・短語、以降第一枝・短語という宣言した参照経路から、可解fixtureを一度構成する。単純根の符号反転と非零区間導関数を確認する。これは独立した未来供給原理ではない。
- 全比較でF=−1、ε=10⁻¹²を固定する。上位でも最終誤差ε/2未満、全ての途中誤差εより大を要求する。

## 結果

数値・検査記録は`integrations/three_plus_one/RR57-result.json`と`RR57-validation.json`。比較の単位は第一輪の「接触、語」である。

| 条件 | 局所で成立する第一輪候補 | 共通上位要求も成立する第一輪候補 |
|---|---|---|
| 保持 | 四接触×二語＝8 | 00・短語 |
| 消去 | 四接触×二語＝8 | 四接触それぞれの短語＝4 |
| 復元 | 8 | 00・短語 |
| γ=0 | 8 | 四接触それぞれの短語＝4 |

保持時の除外された各第一候補について、後続16通りを全て検査する。今回の有限族では、後のsource枝や語の選び直しで補えない。これは全ての可能な継続に対する不可能性の定理ではない。

保持時の最小除外誤差は約1.12612×10⁻⁸で、εの約11,261倍。消去しても「短語である」という上位拘束は残る。保持差によって追加されるのは、四つの接触を区別する拘束である。

別の共通上位文脈を、第一輪01・短語の参照経路から一度構成する。同じ写像と128候補、F・εの下で、保持時は01・短語が残り、消去時はこの有限族に成立経路がない。未来文脈を候補ごと・介入ごとに作り直した比較ではない。

対照として、各第一候補がそれぞれの上位文脈を選び直せるなら、八つの第一候補全てに上位閉鎖の証人を構成できることも検査する。排除は共通要求の下での排除である。二つの共有fixtureの多項式・符号反転区間・導関数区間は検証記録に保存する。

消去時には四接触が同じTE係数へ写る。四つの異なるTE作用が上位で区別できたという意味ではない。第一輪で実行される3+1の接触更新は異なる。先頭に3+1を一回組み込んだTEの接続試験であり、各輪で新しく3+1を学習させる模型へ拡張したものでもない。

## 実際の一履歴と認証

共通上位要求は合否だけを与える。現在の非負整数を、許容経路内の序数として用いる。候補を比較する隔離された予測履歴を、actual在庫へ混ぜない。

確定後は、第一輪で選ばれた一接触について既存の17パラメータ更新と接写像を実行する。第一輪のsourceを下位で実行・認証・公開し、その輪を閉じる。第二・第三輪も、凍結した係数と語を実際の直前の出口へ照合して実行する。確定後に根を解き直したり、候補を探し直したりしない。

同階層のsourceは合計三つだけ増え、stockは4→7。三つのlevel 3出力を上位で実行し、一つのlevel 4セルを認証する。近似終点はその有理数のまま保持し、要求−1へ置換しない。

| 継承するもの | 変換・新規生成するもの |
|---|---|
| 実際の累積値、実行済み語、stock、outputs、rounds、eventsの接頭部分 | 認証済み終端作用の順序付き読出しを次の文脈へ写す |
| 3+1の全基準パラメータ、接触前後、位相と保持差、入口の運搬履歴 | その次の入口で新sourceを構成し、下位で実行・認証してから公開する |
| 完了した各輪の入れ子の作用と実際の終点 | 三出力を同じ上位文脈で実行し、新たな上位セルを認証する |

履歴の選択的消去や圧縮は加えない。高い階層の出力を低い階層の在庫へ混ぜる処理も加えない。

## 再現と搬送

```text
python integrations/three_plus_one/validate_three_flower.py
```

新しい主計算、RR56の主計算、関連テストを実行し、`.work/rr57-local/`へ結果・三つの完了記録を出す。公開済み記録を上書きしない。基準版252テスト全体の再実行とは区別する。

新記録の搬送では元bytesと外部から信頼したSHA-256、期待する上位文脈・介入・γ・自由選択値を必須にする。入口は元のRR56公開記録へ照合し、TE側の実行・継承・認証をexactに再実行する。保存された神経接触後のbinary64値と、全128候補を比較した選択証拠は認証元に束縛した入力である。搬送中に上流SGDや全候補比較を独立に再計算したとはしない。SHA-256は作者の署名ではない。

```text
python integrations/three_plus_one/validate_three_flower.py --transport-only
```

## 到達点と境界

**第一輪だけを見れば成立結果は全て同じ。それでも、内蔵した3+1の保持差がTEの作用差として残り、後続二輪と共通上位要求を通じて、第一輪の許容選択を変える。**

局所の非一意性と、共通上位条件の下での非一意性を分けて実行できる。校正付き部分写像、共通の可解fixture、限定した継続族という条件内での成果である。輪数一般での拘束の単調増大、独立未知な未来からの物理的逆作用、全模型での一意性までは主張しない。
